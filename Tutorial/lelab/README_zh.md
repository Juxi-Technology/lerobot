# LeLab 教程

面向 **LeLab** 的实操教程——LeRobot 的浏览器界面。七篇，从安装 LeLab 一直到在 SO-101 机械臂上跑训练好的策略。

## 七篇

| # | 页面 | 做什么 |
|:--:|---|---|
| 1 | [总览](zh-hans/01-overview.md) | LeLab 是什么、能做什么、需要什么 |
| 2 | [安装与启动](zh-hans/02-install.md) | 装好 LeLab，在浏览器里打开 |
| 3 | [接线与校准](zh-hans/03-calibration.md) | 接上两条臂、选串口、校准 |
| 4 | [遥操作](zh-hans/04-teleoperation.md) | 拖动主臂，从臂跟随 |
| 5 | [录制数据集](zh-hans/05-record-dataset.md) | 带摄像头录 episode |
| 6 | [训练与推理](zh-hans/06-train-and-inference.md) | 训练策略，然后在机械臂上跑 |
| 7 | [常见问题](zh-hans/07-troubleshooting.md) | 实际会踩到的坑 |

第一次读请按顺序。第 3 到第 6 篇的顺序和软件里的页签一致。
