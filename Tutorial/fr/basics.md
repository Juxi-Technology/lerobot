# Notions de base

## **Cliquez sur les deux icônes dans le coin supérieur gauche pour déplier la liste complète des chapitres**

![L'image montre une icône composée d'un point et de trois lignes parallèles, le point à gauche et les trois lignes parallèles disposées de gauche à droite. Dans le document, cette icône apparaît dans le contexte « cliquez sur les deux icônes dans le coin supérieur gauche pour déplier la liste complète des chapitres », en accord étroit avec le contenu environnant, qui mentionne le clic sur ces deux icônes pour déplier le sommaire ; l'icône de l'image est exactement ces « deux icônes », illustrant visuellement la correspondance entre l'icône et le contexte.](../en/images/d03-01.png)

![L'image montre une icône de lecture, un triangle blanc, sur fond noir. Dans le document, cette icône apparaît sous le contenu « Cliquez sur les deux icônes dans le coin supérieur gauche pour déplier la liste complète des chapitres » de la section « Notions de base ». D'après le contexte, cette icône est probablement un bouton de lecture pour du contenu vidéo ou audio ; elle n'a pas de lien direct avec la fonction de dépliage du sommaire décrite dans le document, mais elle reflète globalement que le document peut contenir du contenu multimédia.](../en/images/d03-02.png)
