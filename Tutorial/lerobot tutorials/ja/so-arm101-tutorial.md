# 製品概要

SO-ARM101 は、Hugging Face 傘下の LeRobot チームが製作した**低コストで完全オープンソースの6自由度ロボットアーム**で、教育入門、研究検証、軽量な産業プロトタイピング向けに設計されています。高い柔軟性と完全なオープンソースエコシステムにより、身体性知能とロボティクス技術の応用の障壁を下げます。

### 1. ハードウェア設計：高性能、モジュール式、組み立てとカスタマイズが容易

- **構造材料**：コア構造は 3D プリント部品と補強された耐荷重部品を組み合わせ、ケーブル配線とジョイント設計を最適化して動作の干渉を避け、軽量性と耐久性のバランスを取っています。ユーザーは交換部品や拡張部品を自分でプリントできます。
- **駆動構成**：Follower アームは**6基の 12V 30KG 高トルク磁気エンコーダサーボ**を搭載し、360°磁気エンコーダフィードバックと PID 制御アルゴリズムを組み合わせています — 滑らかでジッターのない動作、高い繰り返し位置決め精度、強いパワーと精密な動きを実現します。
- **ビジョンシステム**：**デュアルカメラ知能ビジョンシステム**を標準搭載しています。エンドエフェクタのカメラが近距離の把持の詳細を捉え、グローバルカメラが作業環境をカバーします。両方のカメラのデータを統合して 3D モデルを構築し、模倣学習に豊富なデータサポートを提供します。
- **制御接続**：USB-C インターフェースを通じて PC や Raspberry Pi に直接接続できるサーボドライバボードを備えています — プラグアンドプレイで、ハードウェア接続の手順を簡素化し、制御環境をすばやく構築できます。

### 2. ソフトウェアエコシステム：LeRobot と深く統合され、ゼロバリアの AI 開発

- **コアフレームワーク互換性**：Hugging Face の **LeRobot オープンソースロボット機械学習フレームワーク**に深く適合し、PyTorch をベースに、事前学習済みモデル、マルチシナリオデータセット、シミュレーション環境を内蔵し、Stanford ALOHA などの著名なオープンソースデータセットと互換性があります。
- **低遅延通信**：**DORA 分散データフローエンジン**を使い、ハードウェアとアルゴリズム間の低遅延なやり取りを実現します。Python は ROS2 より17倍高速に動作し、コードのホットリロードに対応しているため、再起動せずにポリシーをリアルタイムで調整できます。
- **フルスタックオープンソース**：ハードウェアの 3D プリントファイル、ソフトウェア制御コード、AI 学習スクリプト、チュートリアル一式は**完全にオープンソース**です。ユーザーは自由に改変・さらなる開発を行い、パーソナライズされた機能拡張を素早く実装できます。

### 3. 主要な応用シナリオ：入門からデプロイまでの全シナリオに対応

1. **ロボティクス教育の入門**：アームの組み立てや基本プログラミングから AI ポリシーのデプロイまでのエンドツーエンドのチュートリアルを提供し、視覚的な操作インターフェースとサンプルコードを備えているため、初心者でもロボット制御と AI 応用のスキルを素早く習得できます。
2. **研究アルゴリズムの検証**：**模倣学習と強化学習**の研究に焦点を当て、VR による人間の操作データの記録をサポートしてロボットを学習させます。代表的な事例：15秒の操作動画50クリップをもとに、2時間の学習で衣類の折りたたみ、鍵の挿入、材料の仕分けといったタスクを習得できます。
3. **軽量な産業プロトタイピング**：自動化ソリューションを低コストで検証し、**材料ハンドリング、精密組立、部品仕分け**などのシナリオに適合して、産業グレードのロボットアームの中核機能を千元クラスのコストで提供し、迅速なプロトタイプ検証を可能にします。

### 4. 製品の強み

- **圧倒的なコストパフォーマンス**：ベーシック版は約 $100 からで、オープンソース設計が調達と二次開発のコストを下げ、個人、研究室、中小企業によるバッチ導入に適しています。
- **全チェーンオープンソース**：ハードウェア、ソフトウェア、チュートリアルがすべて完全にオープンで技術的な障壁がなく、自由なカスタマイズと機能拡張により多くのシナリオに素早く適合できます。
- **AI 開発に優しい**：LeRobot エコシステムを背景に、事前学習済みモデルとデータセットをワンクリックで呼び出し、データ収集からポリシー学習、デプロイまでの流れ全体を簡素化し、身体性知能アルゴリズムの展開を加速します。
