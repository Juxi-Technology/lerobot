# 제품 개요

SO-ARM101은 Hugging Face 산하의 LeRobot 팀이 만든 **저비용, 완전 오픈소스 6자유도 로봇 팔**로, 교육 입문, 연구 검증, 경량 산업용 프로토타이핑을 목표로 설계되었습니다. 높은 유연성과 완성도 높은 오픈소스 생태계를 갖추어 체화 지능과 로보틱스 기술 적용의 장벽을 낮춥니다.

### 1. 하드웨어 설계: 고성능, 모듈화, 조립과 커스터마이징이 용이

- **구조 재질**: 핵심 구조는 3D 프린팅 부품과 보강된 하중 지지 부품을 결합하고, 케이블 배선과 관절 설계를 최적화해 동작 간섭을 방지하며 경량성과 내구성의 균형을 맞춥니다. 사용자는 교체용 또는 확장 부품을 직접 출력할 수 있습니다.
- **구동 구성**: Follower 암에는 **6개의 12V 30KG 고토크 자기식 엔코더 서보**가 탑재되어, 360° 자기식 엔코더 피드백과 PID 제어 알고리즘을 결합해 매끄럽고 떨림 없는 동작, 높은 반복 위치 정밀도, 강력한 파워와 정밀한 움직임을 구현합니다.
- **비전 시스템**: **듀얼 카메라 지능형 비전 시스템**이 기본 제공됩니다. 엔드이펙터 카메라는 근거리 파지 디테일을 담고, 글로벌 카메라는 작업 환경을 담습니다. 두 카메라의 데이터를 융합해 3D 모델을 구성하고 모방학습을 위한 풍부한 데이터 지원을 제공합니다.
- **제어 연결**: USB-C 인터페이스로 PC나 Raspberry Pi에 직접 연결되는 서보 드라이버 보드가 장착되어 있습니다. 플러그 앤 플레이 방식으로 하드웨어 연결 과정을 단순화하고 제어 환경을 빠르게 구축할 수 있습니다.

### 2. 소프트웨어 생태계: LeRobot과 긴밀하게 통합, 제로 배리어 AI 개발

- **핵심 프레임워크 호환성**: Hugging Face의 **LeRobot 오픈소스 로봇 머신러닝 프레임워크**에 깊이 적응되어 있으며, PyTorch 기반으로 사전학습 모델, 다중 시나리오 데이터셋, 시뮬레이션 환경을 내장하고 Stanford ALOHA 등 잘 알려진 오픈소스 데이터셋과 호환됩니다.
- **저지연 통신**: **DORA 분산 데이터플로 엔진**을 사용해 하드웨어와 알고리즘 간 저지연 상호작용을 구현합니다. Python은 ROS2보다 17배 빠르게 실행되며, 핫 코드 리로드를 지원해 재시작 없이 정책을 실시간으로 조정할 수 있습니다.
- **풀스택 오픈소스**: 하드웨어 3D 프린트 파일, 소프트웨어 제어 코드, AI 학습 스크립트와 전체 튜토리얼 세트가 **완전히 오픈소스**로 공개되어 있습니다. 사용자는 자유롭게 수정하고 추가 개발해 개인화된 기능 확장을 빠르게 구현할 수 있습니다.

### 3. 핵심 응용 시나리오: 입문부터 배포까지 전 시나리오 대응

1. **로보틱스 교육 입문**: 팔 조립과 기초 프로그래밍부터 AI 정책 배포까지의 엔드투엔드 튜토리얼을 제공하고, 시각적 조작 인터페이스와 예제 코드를 갖춰 초보자가 로봇 제어와 AI 응용 역량을 빠르게 습득할 수 있습니다.
2. **연구 알고리즘 검증**: **모방학습과 강화학습** 연구에 중점을 두며, VR로 사람의 조작 데이터를 기록해 로봇을 학습시키는 것을 지원합니다. 대표 사례: 15초 분량의 조작 영상 50개를 기반으로 2시간 학습이면 옷 개기, 열쇠 꽂기, 자재 분류 등의 작업을 습득하기에 충분합니다.
3. **경량 산업용 프로토타이핑**: 자동화 솔루션을 저비용으로 검증하며, **자재 운반, 정밀 조립, 부품 분류** 등의 시나리오에 적합합니다. 천 위안대 비용으로 산업용 로봇 팔의 핵심 기능을 제공해 프로토타입 검증을 빠르게 진행할 수 있습니다.

### 4. 제품 강점

- **압도적 가성비**: 기본 버전은 약 $100부터 시작하며, 오픈소스 설계로 조달 및 2차 개발 비용을 낮춰 개인, 실험실, 중소기업의 배치 도입에 적합합니다.
- **전 체인 오픈소스**: 하드웨어, 소프트웨어, 튜토리얼이 모두 완전히 개방되어 기술 장벽이 없으며, 자유로운 커스터마이징과 기능 확장을 지원해 다양한 시나리오에 빠르게 맞출 수 있습니다.
- **AI 개발 친화적**: LeRobot 생태계를 기반으로 사전학습 모델과 데이터셋을 원클릭으로 호출해 데이터 수집부터 정책 학습, 배포까지의 전 과정을 단순화하고 체화 지능 알고리즘의 출시를 가속합니다.
